# The Ikarion Server Room — The Virtual Gate

**Type:** Monad's server facility — the Ikarion VR world's physical heart
**Hook:** The 6-node starter's lore node (`node_04_ikarion`)

The room where the 28M-player Ikarion world actually lives. One section of the code is a **virtual gate to Ikaris** — players who reach certain levels get transported to the real Prime World. The World Police's intrusion-response team knows this room's secret; most of Imago doesn't.

**The Breach:** When a Xyconal'd neomorph monsters out and the arena's chaos spikes the server, the gate flickers. The party must reach this room to stop the breach — or let the Multiverse bleed into Imago.

**Mechanics:** A `lore` node with a Monad engineer's read — reach it, and the party learns the virtual gate is real, and Ikaris is on the other side (tie to Disc 7).
