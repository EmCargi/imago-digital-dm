# Monad & ONE — The Nexus and the Virtuoids

> **Source:** BESM 4e Chapter 14, pp. 336–337 (Imago).

## Monad

Monad is the computer and software giant. It pioneered the **Nexus** (vast computer network) and the VR operating systems that run on it. Its **Brainscape** gear lets players interact with the Nexus as if in reality, creating avatar bodies. Monad runs **Ikarion** — the 28M-player VR fantasy world that secretly contains the virtual gate to Ikaris.

## ONE

Omniversal Nexus Entertainment (ONE) is the content provider — 3-D movies, computer games, pop stars, investigative news. Its latest creation is **near-sapient "virtuoid" entities** for use as virtual idols, actors, etc., developed with Monad. In a cut-throat business, ONE is especially ruthless. Self-aware virtuoids could one day upload into Exodynamics' android bodies.
